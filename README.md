# Byte-Kit

Fast, private developer tools that run entirely in the browser.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run start
```

Set `NEXT_PUBLIC_SITE_URL` to the deployed site URL so metadata, schema markup,
the sitemap, and `robots.txt` use the correct domain.
